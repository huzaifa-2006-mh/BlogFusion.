# Blog Fusion

A modern, multi-niche blogging platform built with Next.js, TypeScript, and Prisma.

## About Blog Fusion

Blog Fusion is your go-to resource for exploring technology, online earning opportunities, job updates, and entertainment content. Created with passion for sharing knowledge and innovation.

## Features

- 📝 **Multi-Niche Blogging**: Tech, careers, entertainment, and more
- 🎨 **Modern UI/UX**: Beautiful and responsive design
- 📊 **Analytics**: Built-in visitor tracking and analytics
- 🔐 **Secure**: Authentication and dashboard for authors
- 🚀 **Fast**: Optimized with Next.js and Tailwind CSS
- 📱 **Mobile Ready**: Works seamlessly on all devices

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `src/app/page.tsx`. The page auto-updates as you edit the file.

## Tech Stack

- **Framework**: Next.js 16.2.4
- **Frontend**: React 19.2.4 with TypeScript
- **Styling**: Tailwind CSS
- **Database**: Prisma with your preferred database
- **Language**: TypeScript

## Project Structure

```
src/
├── app/              # Next.js App Router pages
├── components/       # Reusable React components
├── lib/             # Utility functions and libraries
└── middleware.ts    # Next.js middleware

prisma/
├── schema.prisma    # Database schema
└── seed.js         # Database seeding

public/              # Static assets
```
